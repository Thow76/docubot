# ADR-0001: Android-only for v1

**Status:** Accepted

## Context

The prototype (`docs/poc-audit.md`) only ever ran on Android. Building and
maintaining an iOS target in parallel with the rebuild would double the
testing/release surface for a single-developer project before there's any
evidence iOS is needed.

## Decision

v1 targets Android only. No iOS build, test, or release. The `ios/` directory
generated by `flutter create` is left untouched — never deleted — but is not
built, tested, or maintained as part of this project.

Package choices may favor Android-native quality over cross-platform parity
where the two conflict (see ADR-0006 for an example).

Platform-specific behavior — camera, notifications, file storage — must sit
behind service interfaces rather than being called directly from screens or
providers.

## Consequences

The service-interface requirement is what keeps a future iOS port merely
tedious rather than a rewrite: platform-specific code stays isolated behind
interfaces the rest of the app already depends on abstractly, so adding an
iOS implementation of those interfaces later doesn't require touching
screens, providers, or the repository layer.
